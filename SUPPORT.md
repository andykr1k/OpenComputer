# Support

OpenComputer is a volunteer open-source project.

## Questions and setup help

Use [GitHub Discussions](https://github.com/andykr1k/OpenComputer/discussions) for setup questions, model compatibility, and general ideas. Include your operating system, desktop session, model, endpoint software, and sanitized error text.

## Bugs

Use the structured [bug report](https://github.com/andykr1k/OpenComputer/issues/new?template=bug.yml) when behavior is reproducible. Search existing issues first.

## Security and conduct

- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).
- Report sensitive conduct concerns according to [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Do not publish API keys, private screenshots, personal messages, or sensitive model prompts in any support channel.
