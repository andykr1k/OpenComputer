# Changelog

All notable changes to OpenComputer will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases will use semantic versioning where practical.

## [Unreleased]

### Added

- Open-source project documentation, community health files, and continuous integration.

## [0.1.0] - 2026-07-22

### Added

- Cross-platform Electron orb and expandable chat interface.
- Local vLLM and remote OpenAI-compatible model configuration.
- Multimodal desktop agent loop with context compaction.
- Mouse, keyboard, scrolling, dragging, screen-region, URL, wait, and clarification tools.
- Per-action and automatic permission modes with keyboard approval shortcuts.
- Task cancellation, system light/dark themes, screenshot verification, and packaging targets.
